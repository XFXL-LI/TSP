# TVOC 日常浓度与状态读取协议

适用版本：standard 2.2.0、certified 2.2.0.1。软件验证与实物验收分开记录。
依据 TVOC_PID20 v1.2.0《标定寄存器协议.md》，不修改底板 MCU。

## 配置、因子及兼容

TVOC 使用 a99054、原 RS485 口、从站3、9600/8N1，是单因子互斥配置。
空气微站保持原有45/60/70秒阶段及120秒周期。选择示例：

    {"operation":"set_config","config":"sensors","mode":"selection","enabled":["a99054"]}

默认单位 ppb；单位及报警设置沿用既有权限、保存和重启生效规则。
旧配置/目录中的 a24035 在内存规范化为 a99054，后续保存和查询使用新 ID。
选择、局部设置、实时查询接受旧 ID 输入别名，并对新旧别名去重。
旧 model 文件只读查询返回规范化 JSON，不主动改写设备配置。

旧 TVOC 历史和 pending 值来自旧算法，不仅改 ID 就当成新 ppb。本次不重写、
重标度或补造旧记录；历史查询仍按原数据和原格式读取。
LCD 应识别查询返回的新 ID，不能继续硬编码旧 ID。

## 只读 Modbus 与状态

首次采样读取256～258确认1.2.0。每槽先读5/6的uint32 ppb，再单独读272～275。
高字在前，不跨寄存器空档，不使用旧 ADC 曲线，不发送标定/设置写命令。
每请求一次尝试、500ms响应预算，并受本槽截止时间限制。

- 浓度或状态读取失败：本点无效，不复用上次浓度或缓存状态。
- 0 ppb 为有效零值，参与平均。
- FFFFFFFF、无完整标定、ADC失败或饱和：无效。
- 标定忙 bit2：排除本点，状态 C。
- 有有效完整参数且当前测量正常时，历史标定失败 state5/error 不单独使读数无效。
- 超过量程 R：保留数值和 T 状态，不截断，不套认证四气体500ppb限制。
- TVOC 模式的 gas_calibration 返回 NG；旧 gal_data 对新旧 TVOC ID 拒绝，
  采集器 gal() 返回 false。

外部标定前通气、清洗等阶段不能仅靠忙位完整识别，本版不提供完整维护会话。
响应过程、稳定时间及毛刺特征留待后续标定联调确认。

## 采样及批次

每120秒开始一轮，开泵70秒，休息约50秒，保留独立关泵定时器。
候选采样窗口为第10～70秒：10、15、20……65秒共12槽。
前10秒通气为待实测的工程默认值，不能据此认定已经稳定。

迟到且错过的槽记无效，不追赶补采、复制旧值或延长到停泵阶段。
关泵保护未能启动时，不进行有效采样。只要有一个有效点就计算算术平均；
没有有效点则本批无效。状态正常的孤立高值保留，不固定去最大/最小值，
不启用未经实测的尖峰剔除。

本轮到达约第70秒后形成一个实时均值，更新 LCD 缓存并走原存储、上传和统计链路；
下一批仍间隔120秒。该值表示选定抽气窗口的样本平均值。
5秒样本不逐点触发 LCD、SD 或 HJ212，不新增任务或采样队列。

分钟（现有10分钟窗）、小时、天继续汇总实时批次均值，数值口径不变；
有效值的 T 状态向后续统计传递。SD 记录布局不变，仍只保存原数值和有效位；
历史读回沿用 N/D 恢复，不声称历史文件额外保存了采样数量或完整模块状态。

## LCD 与诊断

沿用查询应答，显示最近完成批次的均值：

    {"operation":"get_data","ids":["a99054"],"with_status":true}

带 with_status 的 TVOC 回复在 ds 内可追加：

    "tvoc":{"samples":12,"valid":11,"flags":1,"flag":"N"}

samples 为计划槽数（包括错过/失败槽），valid 为有效点数；
flags 为最后槽读取的模块标志，读取失败为0，不冒充有效状态；
flag 为整批 N/T/B/D/C。是否可用仍看 valid_mask。
查询不重新采样或重复累计；尚无首批时不提供 tvoc 对象。
旧请求不增加字段，空气微站回复不变，800字节限制不变。
LCD 后续可按需显示数量，不要求更换查询或启用主动推送。

INFO 的 TVOC_BATCH 输出批次、有效/无效点数、均值、状态及泵启动结果。
单点原始浓度、标志和标定状态/错误留在 DEBUG。

## 单位口径

内部、统计及新 SD 统一 ppb。配置支持 ppb、ppm、ug/m3、mg/m3。
质量单位按用户确认的异丁烯当量、25℃、101.325kPa：

- M=56.1063 g/mol；Vm=R×298.15/101.325，R=8.31446261815324。
- ppm=ppb/1000。
- ug/m3=ppb×M/Vm，系数约2.29329。
- mg/m3=ppb×M/Vm/1000。

这是异丁烯当量，不是未知混合气体逐组分质量之和。
省平台实际接收单位仍以接入要求和配置为准，不能仅凭因子代码推定。

依据：[Honeywell TN-106](https://automation.honeywell.com/content/dam/his-sandbox/products/gas-and-flame-detection/documents/Technical-Note-106_A-Guideline-for-Pid-Instrument-Response.pdf)、
[NIST 异丁烯分子量](https://webbook.nist.gov/cgi/cbook.cgi?Name=methylpropene)。
