# 空气微站气态污染物上传单位与精度说明

## 1. 推荐结论

空气微站上传环境空气气态污染物时，建议采用以下单位和精度：

| 污染物 | 参数代码 | 原始传感器单位 | 实时/分钟上传单位 | 实时值建议精度 | 小时发布值精度 |
|---|---|---|---|---|---|
| O₃ | `a05024` | ppb | μg/m³ | 1 位小数 | 整数 |
| NO₂ | `a21004` | ppb | μg/m³ | 1 位小数 | 整数 |
| CO | `a21005` | ppm | mg/m³ | 3 位小数 | 1 位小数 |
| SO₂ | `a21026` | ppb | μg/m³ | 1 位小数 | 整数 |

不建议将四种气体全部统一成 mg/m³。环境空气常用口径是：O₃、NO₂、SO₂ 使用 μg/m³，CO 使用 mg/m³。

## 2. 换算方法

按照 25 ℃、1013.25 hPa 的参比状态换算：

```text
质量浓度 = 体积浓度 × 污染物摩尔质量 / 24.45
```

- O₃、NO₂、SO₂：体积浓度输入 ppb，结果为 μg/m³。
- CO：体积浓度输入 ppm，结果为 mg/m³。
- 应先换算并保留内部计算精度，统计完成后再按上传要求修约。

常用换算系数：

```text
O₃  (μg/m³) = O₃  (ppb) × 1.96319
NO₂ (μg/m³) = NO₂ (ppb) × 1.88180
SO₂ (μg/m³) = SO₂ (ppb) × 2.62004
CO  (mg/m³) = CO  (ppm) × 1.14560
```

## 3. 示例

原始数据：

```text
O₃  = 15 ppb
NO₂ = 0 ppb
CO  = 1.586 ppm
SO₂ = 0 ppb
```

实时或分钟数据建议上传为：

```text
O₃  = 29.4  μg/m³
NO₂ = 0.0   μg/m³
CO  = 1.817 mg/m³
SO₂ = 0.0   μg/m³
```

计算小时平均并用于 AQI 或对外发布时，建议修约为：

```text
O₃  = 29  μg/m³
NO₂ = 0   μg/m³
CO  = 1.8 mg/m³
SO₂ = 0   μg/m³
```

## 4. 程序处理建议

```text
读取传感器 ppb/ppm 原始值
    ↓
转换为参比状态质量浓度
    ↓
保留未修约值用于存储和统计
    ↓
实时/分钟上传：
O₃、NO₂、SO₂ 保留 1 位小数
CO 保留 3 位小数
    ↓
使用未提前修约的数据计算小时平均
    ↓
小时发布：
O₃、NO₂、SO₂ 修约为整数
CO 修约为 1 位小数
```

不要先对每个实时值取整再计算平均值，否则会引入累计误差。

## 5. 与 HJ 212 的关系

HJ 212-2017 和 HJ 212-2025 主要规定通信报文、字段和传输过程。其附录中的部分气监测默认单位偏向污染源废气口径，不能直接等同于环境空气微站口径。

因此建议：

1. 使用 HJ 212 组织报文和传输字段。
2. 使用环境空气口径确定上述四种污染物的单位和精度。
3. 如果接收平台明确要求全部使用 mg/m³，应以平台接口文档为准，并与平台确认 O₃ 参数代码及小数位。
4. 报文中的数字不需要补前导零，例如发送 `29.4`，不需要发送 `0029.4`。

## 6. 异常数据处理

- 实际测量为零时，可以上传 `0.0` 或对应发布精度的 `0`。
- 缺测、通信失败、仪器故障、校准或维护期间的数据不能当作零值上传。
- 异常数据应保留数据状态，并使用 HJ 212 的 `Flag` 字段标识。
- 不要为了避免负数而无条件将所有负值改为零；应按照设备检出限、质量控制规则和平台要求处理。
