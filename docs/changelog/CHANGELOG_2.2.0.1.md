## 功能范围

新增TVOC日常浓度和状态读取，正式因子a99054，支持旧配置和实时请求a24035输入别名。
TVOC单因子模式复用原RS485、泵、采集任务、LCD查询、SD及HJ212；空气微站路径保留。
底板协议为TVOC_PID20 v1.2.0，直接读ppb，不再使用旧ADC电压曲线。

候选10～70秒窗口每5秒采样，共12槽；每120秒形成一批均值。
零值有效，读取/状态失败及忙态排除；有一个有效点即平均并标注有效数量。
错过的槽不补造，孤立高值保留，超量程保留原值及T状态并传递到统计。
LCD显示批次均值，with_status可附加ds.tvoc数量和状态，不改主动推送。
质量单位采用异丁烯当量、25℃、101.325kPa，支持四种单位。
不接TVOC标定写操作，不修改底板MCU，不重写旧SD/pending，不改历史记录布局。
认证四气体限值和校准策略不作用于TVOC。

## 验证

两版TVOC实际源码主机回归通过，覆盖协议/状态、12槽/回绕、部分或全失败、

HJ212回归覆盖2017/2025、实时/分钟/小时/日和四种TVOC单位。
