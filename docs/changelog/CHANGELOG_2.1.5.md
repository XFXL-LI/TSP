## 主要变化

继承[2.1.4](CHANGELOG_2.1.4.md)的发送、待存和臭氧修改，新增每次启动自动执行一次的
SD对照流程，用于定位HJ212缺头问题。阶段由MCU单调毫秒时钟驱动：

| 阶段 | 行为 |
|---|---|
| `on_a` | SD正常业务30分钟 |
| `draining` | 禁止新SD业务，等待已经开始的操作返回 |
| `off_b` | 在途操作归零后，完整暂停SD业务60分钟 |
| `on_a2` | 恢复正常SD业务30分钟 |
| `complete` | 继续正常业务，不循环；再次启动才重新执行 |

- 暂停覆盖历史保存/查询、pending读写/扫描/删除/重建，以及SD挂载重试。
- 暂停期间采集、统计、公网上传和LCD实时查询继续；跳过的历史事件释放引用，待存
  请求被拒收或清理并记录未受持久化保护，历史查询返回原有NG响应。
- 阶段切换不重启MCU，不卸载、格式化SD，也不清空既有pending文件或改写FFat设置。
  已经阻塞在SDK内部的调用不能被强行取消，须实际返回后才进入完整静默阶段。
- 增加`SD_ABA_START/PHASE/STATUS/SKIPS`、`SD_IO_BEGIN/END`和实际UART优先级、
  阶段、前缀等诊断输出，使用固定大小状态并复用现有任务。

## 使用限制与验证

本版本是定位用诊断固件。暂停期间跳过的历史和待传项不会恢复补写；恢复后新形成的
统计记录仍可能包含暂停期间采集的数据。不能把此流程当作持续正常存卡模式。

两版各19组控制回归、气体/SD挂载/get_data回归和当前源码上传测试通过，覆盖阶段
边界、慢I/O排空、计时回绕、一次执行、暂停时UART继续、存储/挂载拒收、待存释放及
查询返回。主机优先级模型仍有[2.1.4](CHANGELOG_2.1.4.md)所述局限，后续由2.1.6修正。

certified现场对照发现实际发送等级仍可能为9，结果见[2.1.5.1](CHANGELOG_2.1.5.1.md)。
相关性不等于GPIO波形根因证明，standard尚未取得对应现场接收验证。
