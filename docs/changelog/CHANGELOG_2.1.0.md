# Firmware 2.1.0 变更记录

最后更新：2026-09-20
Variant：standard
状态：`compiled-not-hardware-verified`

## 主要变化

- 实时数据批次固定为120秒；`collect_time`和`upload_interval`继续使用秒作为单位，
  运行时及配置查询/写入均归一为120。
- 启用任一颗粒物或气体因子时，气泵从批次第0秒启动，并由独立一次性定时器在第70秒
  关闭；未启用空气通道因子时不启动气泵。
- 其他传感器从第45秒采集；颗粒物和气体在通气60秒后、气泵仍运行时依次读取。
- 颗粒物使用`01 03 00 10 00 08 45 C9`对应的一次批量读取，解析PM1、PM2.5、PM10、
  TSP四个通道，但只输出配置中启用的逻辑因子。
- 四个气体模组使用500 ms操作间隔；组合读取`0x6000/0x6001`通信成功但Bit15未置位时，
  在共享间隔后额外复读一次。原有通信超时和最多3次尝试策略保持不变。
- 10分钟统计继续按完整窗口关闭；小时统计改为纳入每个有效120秒实时批次，不再采用
  “分钟数为3的倍数”抽样。
- 实时批次完成后仍通过现有事件链立即进入SD存储和HJ212上传，没有新增第二个上传定时器。
- LED页面轮播窗口保持60秒，避免采集周期翻倍导致单页停留时间同步翻倍。

## 配置兼容

旧FFat中的60秒值在启动时不会触发自动擦除或自动改写；固件仅在运行时使用120秒，
配置查询返回120，下一次明确写入`systemConfig`时持久化120。
