# Firmware 2.0.19 变更记录

## 版本定位

- 2.0.19以2.0.18通用优化版为基线，修正空气微站HJ 212-2017报文。
- 不恢复2.0.17认证气体封顶；O3、NO2、SO2和CO继续使用2.0.18通用气体策略。
- 小时统计逻辑、传感器读取优化、HJ212逐包3000 ms、SHT30独立和DEBUG开启保持不变。

## HJ 212报文修正

- CRC改为HJ 212-2017附录A算法。标准自带测试向量结果为`1C80`。
- 非累计监测因子的分钟、小时和日数据不再生成`Cou`。
- CP字段由统一追加器生成，最后一个字段后不再保留多余分号。
- HJ212数字改用无字段宽度的`snprintf()`格式化，修复`ppb`为0或一位整数时由
  Arduino `String(float, 0)`产生的前导空格。
- HJ212输出边界把内部O3键`w34011`映射为`a05024`，不自动改写FFat旧配置。
- HJ212输出边界把内部噪声键`L90`映射为`LA`。
- `CN=2011`噪声生成`LA-Rtd`；`CN=2051`、`2061`和`2031`统一生成
  `LA-Data`、`LMx-Data`和`LMn-Data`。
- 噪声采集或统计无有效数据时不生成噪声字段，避免把故障上传为`0.0 dB`。
- 组包器同时识别O3新旧键，历史SD记录重建报文时也能输出`a05024`。

## 气体单位策略

- 保留`ppb`、`ppm`、`ug/m3`和`mg/m3`四种配置化上传单位。
- 现场根据目标平台的因子单位定义手动配置，不在固件中强制写死某一种单位。
- 实时、分钟、小时和日数据的`Rtd/Min/Avg/Max`均按当前配置单位换算。
- 换算继续位于HJ212输出层。固定线性倍数对`Min/Avg/Max`的结果与换算后再统计
  一致，因此不修改现有小时统计逻辑。

## 本次明确不实施

- 不实现HJ212分包。
- 不新增1024/950运行时硬拦截；继续按最终数据段计算四位实际长度。
- 不全局重命名内部`w34011`和`L90`键。
- 不在启动时自动迁移或写回设备FFat。
- 不实现真正的声学`L90`或`Leq`计算；`LA-Data`仍为当前已有窗口算术平均值。

## 验证

标准CRC向量：

```text
QN=20160801085857223;ST=32;CN=1062;PW=100000;MN=010000A8900016F000169DC0;Flag=5;CP=&&RtdInterval=30&&
CRC=1C80
```

零值、因子映射和尾部分号测试报文：

```text
##0170QN=20260902120000001;ST=22;CN=2011;PW=123456;MN=qqqqqq12345678;Flag=5;CP=&&DataTime=20260902120000;LA-Rtd=56.8;a21005-Rtd=0.000,a21005-Flag=N;a05024-Rtd=0,a05024-Flag=N&&0D80\r\n
```

该测试报文确认：CRC=`0D80`、气体零值无前导空格、O3只输出`a05024`、噪声只
输出`LA`、CP最后一个字段后无分号。
