# Firmware 2.0.16 变更记录

## 版本定位

- 2.0.15 保留为已验证的正式基线，不回改。
- 2.0.16 是面向正常、未做特殊量程限制传感器的通用正式版本。
- O3、NO2、SO2 的 500 ppb 显示封顶及 250 ppb 量程校准目标属于后续特定认证版本，不包含在 2.0.16。

## 本次修复

### 颗粒物采集与校准

- PM1、PM2.5、PM10、TSP 的原生浓度 `0` 改为有效数据；`0xFFFFFFFF` 仍作为无效寄存器值处理。
- 移除 TSP 采集中的韶钢专用分段压低系数，直接使用原有双次采样平均值和单位换算。
- PM1、PM2.5、PM10、TSP 的 `gal()` 改为统一出口释放 TTL 互斥锁：写寄存器失败、回读失败或校验不一致时均返回失败并正常释放锁。
- 原有颗粒物 increment/ratio 校准寄存器、双次采样平均及单位换算保持不变。
- `TspCollect.cpp` 从原 GB18030 编码转换为 UTF-8；除上述明确列出的逻辑外未做额外业务修改。

### HJ212 配置

- 修复 `/hj212.json` 中 `flag` 已保存但启动加载时未解析，运行时始终沿用默认 `Flag=9` 的问题。
- 补充解析 `timeout`、`retry_times`。
- 协议版本优先读取完整字段 `protocol_version`，同时兼容旧配置字段 `pv`。
- 默认 HJ212 配置模板统一使用 `protocol_version`。
- 启动配置日志增加 Flag、协议版本、超时及重试次数，便于核对实际生效值。
- 配置生效方式维持现状：写入 FFat 后重启 MCU，由启动加载应用新配置。
- 已经落盘的历史待重传 `.pkt` 保存的是生成时的完整报文，重传时仍会保留原来的 Flag，不做删除或重写。

## 明确保持不变

- 四气体普通采集数据不封顶。
- 气体量程校准目标保持 O3=500 ppb、NO2=500 ppb、CO=5000 ppb、SO2=500 ppb。
- 小时统计逻辑不改。
- HJ212 逐包等待保持 3000 ms。
- SHT30 保持独立。
- DEBUG 保持开启。
- 2.0.15 已完成的四气体异步校准及 cancel/finish 竞态修复保留。
