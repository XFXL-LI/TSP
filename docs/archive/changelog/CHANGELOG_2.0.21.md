## 本版目标

在 Firmware 2.0.20 通用版基础上完善 HJ212-2017 数据状态、9014 应答、QN 唯一性、发送配置生效和 pending 写入保护。通用版继续保留气体模块原始量程，不加入认证封顶。

## 1. 因子状态

- 数据状态在采集、处理和 HJ212 打包链路中独立传递，不再只根据 `is_valid` 二选一生成 `N/D`。
- 当前自动状态：
  - `N`：正常；
  - `B`：Modbus/串口通信失败或总线锁获取失败；
  - `D`：传感器内部故障、未就绪，或颗粒物寄存器返回无效值；
  - `T`：气体超量程/高浓度保护，或气压超出物理范围；
  - `C`：气体校准期间；
  - `M`：远程 MCU OTA 开始前的一次性维护状态通知。
- `F`、`S` 已保留为协议状态，但本版不会在没有明确业务来源时自动生成。
- 无效状态数据仍不参与分钟、小时和日统计；小时有效样本的取样规则未改变。
- 统计窗口内只要存在有效样本，聚合报文状态为 `N`；整窗没有有效样本时才输出该窗口已观察到的无效原因。
- SD 历史记录二进制结构保持不变。旧记录重建报文时仍只能恢复为原有 `N/D`；完整 pending 报文本身会保留真实状态。
- 噪声继续按 `LA/LMx/LMn` 形式上报，不额外增加标准中未定义的 `LA-Flag`。

气体模块仍只执行一笔 FC03 事务，但从 `0x6000` 起一次读取 2 个寄存器：状态寄存器和 `0x6001` 浓度寄存器。这样不会增加每个气体因子的 Modbus 事务次数。

## 2. 9014 应答校验

新增 `ack_mode` 配置，默认 `compatible`：

- `standard`：必须是完整 `##` 帧，长度、CRC、`CN=9014`、QN、MN 和 `QnRtn=1` 全部正确；
- `compatible`：完整帧仍严格校验长度和 CRC；非完整平台回复必须具有边界明确的 `CN=9014`，回复中只要带 QN、MN 或 `QnRtn` 就必须分别匹配、匹配和等于 1；
- `legacy`：仅为已确认使用非标准 ACK 的平台保留旧式 `CN=9014` 兼容判断。检测到格式损坏的 `##` 帧时仍不会降级放行。

程序不会自动从严格模式降级。日志新增 `ACK_ACCEPT`、`ACK_REJECT reason=...`，不打印 MN、PW 或完整报文。

## 3. QN 唯一性

- QN 改为 `yyyyMMddHHmmssSSS`，使用系统真实毫秒。
- 同一毫秒内生成多包时使用受临界区保护的单调序号推进，避免实时、分钟和小时边界并发生成重复 QN。
- 同一个报文的发送重试继续使用原 QN；从 SD 数据重新构建的新报文生成新 QN。

## 4. timeout/retry_times 生效

- 普通实时和统计上传使用 `/hj212.json` 中的 `timeout` 与 `retry_times`。
- 默认值仍为 5 秒、3 次。
- 防御范围：`timeout` 1–60 秒，`retry_times` 1–10 次。
- pending 补传仍显式限定为单次尝试，避免旧包长期独占发送链路。
- 每包之间固定 3000 ms 间隔未改变；重试间隔仍为 5000 ms。

## 5. pending 写入保护

- 第一次使用 `stdio + fflush + fsync + close` 写临时文件并逐字节校验。
- 第一次写入或校验失败时，删除临时文件，等待 20 ms 后使用独立 POSIX `open/write/fsync/close` 路径重写一次。
- 校验异常日志新增：尝试次数、写入方法、文件大小、首个不一致偏移及字节、内存/文件 CRC32、前 128 字节零值数量、空闲堆、最大连续堆和任务剩余栈。
- 只有完整校验成功的临时文件才能原子改名为 `.pkt`。
- 已存在且通过完整 HJ212 校验的 pending 文件不会被覆盖；已损坏的旧文件可替换为 `REBUILD_FROM_SD` 标记。
- 两次写入都失败时仍回退到 SD 重建标记，现有补传公平调度保持不变。

## 6. OTA 的 M 状态

- 仅远程 OTA 能在固件仍运行时自动发送一次 `CN=2011`、因子状态 `M` 的快照。
- 使用最近一轮有效数据；无有效快照、HJ212 关闭或网络状态不可用时只记录跳过原因。
- 该通知只尝试一次，失败不会取消、阻断或改变后续 OTA 流程，也不会进入 pending 队列。
- USB/串口直接烧录无法由旧固件预知，因此不会自动产生 `M` 报文。

## 冻结约束确认

- 小时统计的有效值取样逻辑未改；
- HJ212 逐包间隔保持 3000 ms；
- SHT30 保持独立；
- DEBUG 保持开启；
- 未烧录、未擦除 MCU、未操作设备 FFat。
